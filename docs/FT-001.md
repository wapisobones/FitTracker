# FT-001 — Base ejecutable y estructura visual

## Alcance implementado

Dashboard ilustrativo, estructura compartida y navegación a Inicio, Ejercicios, Mis rutinas, Generador, Rutinas prediseñadas, Rutina activa, Progreso, Herramientas, Calculadora de 1RM, Calculadora de calorías y Perfil. Las secciones pendientes explican su propósito y deshabilitan las acciones sin implementación. Un enlace desconocido muestra una salida a Inicio.

## Referencias y diseño

Se revisaron AGENTS.md, FITTRACKER-SPEC.md y README.md completos antes de implementar. La skill frontend-design guió la selección de tokens y la revisión visual sin sustituir la identidad aprobada.

- Referencia principal: `mockups/01-dashboard.png`.
- Referencias móviles: `04-ejercicios-mobile-modal.png`, `06-mis-rutinas-mobile.png`, `10-rutina-activa-mobile.png` y las variantes incluidas en los mockups de Progreso, Herramientas, Perfil y Prediseñadas.
- Se revisaron también las referencias de escritorio de las vistas base correspondientes.
- Paleta: fondo `#0b121b`, sidebar `#0e1721`, tarjeta `#151e28`, borde `#303e4c`, texto `#f3f5f7` y acento `#9bf45c`. Ámbar reservado al volumen y trofeo.
- Tipografía de sistema: Segoe UI para lectura y Bahnschrift / Arial Narrow para títulos y cifras; sin fuentes remotas.
- Composición: sidebar fija; encabezado; cuatro indicadores; carga y distribución muscular; historial y objetivos. En móvil, indicadores en dos columnas, contenido en una columna, menú completo modal y navegación inferior.

El mockup incorpora un objetivo de proteína. Se sustituyó por volumen de entrenamiento para mantener esta etapa dentro de las métricas documentadas en la especificación. Los SVG de iconos, montañas y esquema corporal son locales y originales; no se incorporaron fotografías, vídeos ni recursos de terceros.

## Decisiones técnicas y de comportamiento

- HTML, CSS y ES modules. Vite solo para servir y compilar; Playwright solo para comprobar en navegador. Dependencias gestionadas con pnpm y lockfile versionado.
- Assets relativos y rutas por hash: una sección conserva su URL al recargar bajo `/FitTracker/`, sin backend ni reescrituras.
- Las cifras, fechas y porcentajes del Dashboard provienen de fixtures estáticos en `src/data/dashboard-demo.js`; no son cálculos ni historial personal. No representan la fecha actual. El aviso de demostración permanece visible en Inicio.
- No se accede a IndexedDB, localStorage, API ni datos reales. No existe todavía selector demo/personal ni primera visita. No se realizan escrituras ni cambios de modo aparentes.
- La búsqueda es un campo deshabilitado con explicación de disponibilidad. Los selectores de periodo y ejercicio del mockup se presentan como etiquetas porque aún no hay filtros.
- El enlace «Ver historial» navega a la vista base de Progreso, donde se explica que el historial aún no está implementado.
- Los objetivos son ejemplos fijos, sin edición ni cálculos. El volumen semanal ilustrativo coincide con los tres entrenamientos mostrados.
- Menú móvil con `dialog` nativo: foco contenido en el diálogo, cierre con Escape, cierre al navegar y cierre al cambiar a escritorio. Navegación con `aria-current`, foco visible, salto al contenido y tabla accesible para el gráfico de carga.
